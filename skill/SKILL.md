# Бот-модератор комментариев Telegram

## Что ты создаёшь

Бота для **чата комментариев** Telegram-канала (связанная группа обсуждений).
Он делает три вещи:

1. **Удаляет спам** — предложения заработка, «пиши в личку», подозрительные
   ссылки, приглашения в другие каналы. Банит отправителя при высокой
   уверенности.
2. **Убирает служебные сообщения** — «X теперь в группе», «X покинул группу»,
   смена названия и фото чата. Настройками Telegram их скрыть нельзя.
3. **Управляется целиком из Telegram** — меню с кнопками, смена режима,
   белый список, база образцов спама. Владельцу не нужен сервер и SSH.

Стек: Python 3.10+, aiogram 3, SQLite, systemd. Без платных API, без Docker,
без внешних сервисов. Работает на сервере за ~500 ₽/мес.

## Порядок работы

**ОБЯЗАТЕЛЬНО прочитай `ЛОВУШКИ.md` перед началом.** Там одиннадцать вещей,
на которых спотыкается почти каждый, кто делает такого бота впервые.

### Этап 1. Вопросы

Задай **не больше 7** вопросов одним списком, с рекомендацией по умолчанию:

1. Бот через @BotFather создан? Комментарии к каналу включены?
2. Один канал или несколько?
3. Есть ли примеры реального спама из чата (5–15 сообщений текстом)?
4. Строгость: банить только очевидное, или удалять и сомнительное?
   *По умолчанию: очевидное — бан, сомнительное — удаление без бана.*
5. Присылать уведомления о срабатываниях? *По умолчанию: да.*
6. Есть ли сервер? Какой бюджет в месяц? *По умолчанию: ~500 ₽.*
7. Есть ли второй Telegram-аккаунт для безопасной проверки бана?

**Не спрашивай** про язык, фреймворк, базу данных, webhook или polling,
Docker, архитектуру — это решено в шаблоне.

**Никогда не проси прислать токен в переписку.**

Дождись ответов. Не пиши код до них.

### Этап 2. Проект

Скопируй шаблон. Настрой `bot/rules.yml` под присланные примеры спама:
добавь характерные фразы, но **не затачивай под конкретные тексты** —
фильтр должен ловить и новые формулировки.

Прогони тесты и покажи результат:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install pytest
.venv/bin/python -m pytest tests -q
```

Добавь присланные пользователем примеры в `tests/samples.py` и убедись,
что все ловятся, а нормальные сообщения — нет.

### Этап 3. Действия пользователя в Telegram

Дай **не больше трёх действий за раз**, скажи, что он должен увидеть:

1. **@BotFather → /mybots → бот → Bot Settings → Group Privacy → Turn off.**
   Должно появиться «Privacy mode is disabled». Без этого бот не видит
   комментарии вообще.
2. **Добавить бота администратором** в группу обсуждений (не в канал!)
   с правами «Удаление сообщений» и «Блокировка пользователей».
3. **Узнать свой ID** через @userinfobot и прислать его.

### Этап 4. Сервер

Сравни не больше трёх вариантов и порекомендуй один. На 2026 год для России:

| Хостер | Минимальный тариф | Регион | Оплата |
|---|---|---|---|
| **Beget** | ~330 ₽/мес + 150 ₽/мес за IPv4 | СПб | карты РФ, СБП |
| Timeweb Cloud | от 900 ₽/мес | Москва, СПб | карты, СБП, ЮMoney |
| Selectel | от ~700 ₽/мес | Москва, СПб | карты РФ, счёт |

**Проверь цены заново** — они меняются. **Обязательно предупреди, что
публичный IPv4 тарифицируется отдельно**, иначе итоговая сумма окажется
в полтора раза выше названной.

Сервер в России упрощает вопрос с хранением Telegram ID. Не давай
юридических заключений — просто отметь это как более осторожный вариант.

**Ничего не арендуй и не оплачивай без явного подтверждения пользователя.**

Порядок:
1. Сгенерируй SSH-ключ на машине пользователя, покажи **публичную** часть:
   `ssh-keygen -t ed25519 -f ~/.ssh/moderator_bot -N "" -C "moderator-bot"`
2. Пользователь создаёт сервер (Ubuntu 24.04 или новее), вставляет публичный
   ключ в поле SSH-ключа, присылает IP.
3. Скопируй проект и запусти установку:
   ```bash
   tar --exclude='.venv' --exclude='data' --exclude='.env' \
       --exclude='__pycache__' --exclude='.pytest_cache' \
       --exclude='.DS_Store' --exclude='._*' -czf /tmp/moderator.tgz .
   scp -i ~/.ssh/moderator_bot /tmp/moderator.tgz root@IP:/tmp/
   ssh -i ~/.ssh/moderator_bot root@IP '
       mkdir -p /opt/moderator
       tar -xzf /tmp/moderator.tgz -C /opt/moderator
       find /opt/moderator -name "._*" -delete
       cp /opt/moderator/.env.example /opt/moderator/.env
       bash /opt/moderator/deploy/install.sh'
   ```
4. Впиши в `.env` на сервере `ADMIN_ID`, `MODE=observe`.
5. Токен — только через `deploy/set_token.sh`:
   ```bash
   bash deploy/set_token.sh root@IP
   ```
   Пользователь вводит токен скрытым вводом, тот идёт прямо на сервер.

### Этап 5. Проверка перед боевым режимом

1. Пользователь нажимает **Start** в личке бота — Telegram не даёт боту
   написать первым.
2. В группе комментариев пишет `/id` — бот отвечает ID чата.
3. Впиши этот ID в `CHAT_IDS` и перезапусти службу.
4. Перезагрузи сервер (`systemctl reboot`) и убедись, что бот поднялся сам.
5. Пользователь со второго аккаунта пишет в чат спам и обычное сообщение.
   Должно прийти уведомление **только на спам**.

Покажи короткий результат: что проверено, что прошло, готов ли боевой режим.

**Включай удаление и бан только после явного подтверждения.** Предложи
начать с `soft` (удаляет, не банит) на неделю.

## Что делает бот — расскажи пользователю

**Ловит:** обычный текст и подписи к медиа, отредактированные сообщения,
скрытые под текстом ссылки, пересылки из чужих каналов, спам в имени
и @username, повторы одного текста от разных аккаунтов, обход фильтра
(лишние пробелы, невидимые символы, латиница вместо кириллицы, цифры
вместо букв).

**Не трогает:** владельца, администраторов чата, самого бота, белый список.
Одно слово «работа», «деньги» или «доход» срабатыванием не является —
решение принимается только по сочетанию признаков.

**Три режима:** `observe` (только уведомления), `soft` (удаляет, не банит),
`enforce` (удаляет и банит).

**Управление из Telegram:** `/menu` — меню с кнопками. Смена режима, пауза,
перезапуск, статистика, последние срабатывания с текстом, база образцов
спама, белый список, разбан, добавление правил, пороги.

**База образцов:** кнопка «Запомнить как спам» под уведомлением сохраняет
текст. Похожие сообщения удаляются сразу. Сравнение по «скелету» без цифр,
поэтому «5000 в день» и «9000 в день» — один образец.

**Сам за собой следит:** раз в час проверяет свои права админа, раз в сутки
присылает сводку, чистит журнал старше 90 дней.
