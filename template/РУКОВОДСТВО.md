# Руководство: все команды бота

Полное описание того, что умеет бот и как этим пользоваться.
Программировать не нужно, сервер открывать не нужно — всё делается
в Telegram, в личной переписке с ботом.

Все команды работают **только для владельца** — того, чей Telegram ID указан
в настройке `ADMIN_ID`. Участники чата их не видят и воспользоваться ими
не могут.

---

## С чего начать

Откройте бота в личке и нажмите **Start** (то же самое — команда `/start`).
Придёт два сообщения, и под полем ввода появятся шесть постоянных кнопок. Слева от поля ввода — кнопка
**«Меню»** со списком всех команд.

Дальше можно вообще не набирать команды: почти всё делается кнопками.

---

## Шесть кнопок под полем ввода

Это кнопки **просмотра** — они всегда на виду и ничего не меняют.

| Кнопка | Что показывает |
|---|---|
| 📊 **Состояние** | режим работы, пороги, белый список, все настройки |
| 📈 **Статистика** | сколько сработало за сутки и за неделю |
| 📋 **Последние** | последние срабатывания: кто, когда, за что, что сделано, текст сообщения |
| 🚫 **Образцы** | сохранённые образцы спама |
| ⚙️ **Режим** | текущий режим и кнопки переключения |
| ❓ **Команды** | список всех команд с пояснениями |

## Кнопки внутри сообщений

Это кнопки **действий** — появляются там, где нужны.

Под сообщением «⚙️ Режим»:

| Кнопка | Действие |
|---|---|
| 👀 **Наблюдение** | бот только сообщает о находках |
| 🧹 **Мягкий** | удаляет спам, никого не банит |
| 🛡 **Боевой** | удаляет спам и банит нарушителей |
| ⏸ **Приостановить** | бот замолкает, ничего не проверяет |
| 🔄 **Перезапустить** | перезапуск бота |

Под уведомлением о пойманном спаме:

| Кнопка | Действие |
|---|---|
| ✅ **Не спам** | разблокирует человека и добавит в белый список |
| 🔓 **Разблокировать** | просто снимает блокировку |
| 🚫 **Запомнить как спам** | сохраняет текст образцом, похожие удаляются сразу |

Под разбором пересланного сообщения:

| Кнопка | Действие |
|---|---|
| 🚫 **Спам** | запомнит образец, удалит все сообщения автора и заблокирует его |
| 💾 **Только запомнить** | сохранит образец, автора не тронет |

## Как добавить пропущенный спам — три способа

Самое частое действие. Бот пропустил рекламу — научите его.

**Способ 1. Переслать сообщение.** В чате нажмите на сообщении «Переслать»
и выберите бота. Он разберёт текст и покажет:

```
Баллы: 3 из 4 нужных
Решение: пропустил бы
Не хватило баллов: 1
Признаки: сумма 4600

  🚫 Спам — удалить и заблокировать
  💾 Только запомнить, не трогать
```

**Одно нажатие на «Спам» делает всё сразу:**

1. запоминает образец — похожие сообщения будут удаляться автоматически;
2. удаляет все сообщения этого человека в чате за последние двое суток —
   не только пересланное, но и те, что бот раньше пропустил;
3. блокирует его.

Что именно произойдёт, зависит от режима, и подпись кнопки говорит честно:

| Режим | Кнопка | Что сделает |
|---|---|---|
| боевой | 🚫 Спам — удалить и заблокировать | запомнит, удалит, заблокирует |
| мягкий | 🚫 Спам — запомнить и удалить | запомнит и удалит, без блокировки |
| наблюдение | 💾 Запомнить как спам | только запомнит |

Вторая кнопка — **«Только запомнить, не трогать»** — на случай, когда образец
нужен, а человека трогать не хочется.

**Когда бот не сможет навести порядок.** Если отправитель скрыл профиль
в настройках пересылки, его идентификатор боту не виден — тогда останется
только запомнить образец. Бот сразу об этом предупредит.

**Способ 2. Скопировать текст** и вставить боту в личку. Разбор будет
такой же, но автор неизвестен — сохранится только образец.

**Способ 3. Команда** `/spam текст объявления` — сохранит образец сразу,
без разбора.

### Как работают образцы

Бот сравнивает не буквы, а «скелет» сообщения: без цифр, пробелов и знаков
препинания. Поэтому «Работа на дому, 5000 в день» и «Работа на дому,
9000 в день» — **один и тот же образец**. Перестановка слов и мелкие правки
тоже узнаются.

Слишком короткие тексты (меньше 20 букв) не сохраняются — иначе под них
попадали бы обычные реплики вроде «спасибо».

## Команды по темам

### Посмотреть, что происходит

| Команда | Что делает |
|---|---|
| `/start` | приветствие и кнопки управления |
| `/menu` | меню с кнопками |
| `/status` | режим, пороги, белый список, все настройки |
| `/stats` | срабатывания за сутки и за неделю |
| `/last` | последние 10 срабатываний с текстом сообщений |
| `/samples` | сохранённые образцы спама с номерами |

### Режимы работы

| Команда | Что делает |
|---|---|
| `/mode observe` | **наблюдение** — только уведомления, ничего не удаляет |
| `/mode soft` | **мягкий** — удаляет спам, никого не банит |
| `/mode enforce` | **боевой** — удаляет и банит |
| `/pause` | приостановить проверку (бот работает, но молчит) |
| `/resume` | возобновить проверку |
| `/restart` | перезапустить бота, вернётся через несколько секунд |

Режим сохраняется и переживает перезапуск. Начинать всегда стоит
с наблюдения, через неделю переходить к мягкому, потом к боевому.

**Пауза — это не остановка сервера.** Бот остаётся запущенным, просто
ничего не проверяет. Для повседневных задач этого достаточно.

### Работа с правилами

| Команда | Что делает |
|---|---|
| `/check текст` | проверить любой текст, не трогая чат |
| `/spam текст` | запомнить образец спама |
| `/delsample 5` | удалить образец по номеру из `/samples` |
| `/addword группа фраза` | добавить фразу в правила |
| `/delword фраза` | убрать добавленную фразу |
| `/threshold delete 5` | порог удаления |
| `/threshold ban 7` | порог блокировки |
| `/reload` | перечитать правила из файла |

**Группы для `/addword`:**

| Группа | Для чего |
|---|---|
| `job_offer` | формулировки предложения работы |
| `contact_cta` | призывы написать в личные сообщения |
| `easy_money` | обещания лёгкого дохода |
| `slang_recruit` | жаргон вербовщиков |
| `send_material` | «скину материал в личку» |
| `age_bait` | «без опыта», «с 16 лет» |
| `personal_deal` | **личные объявления** — снижают оценку, а не повышают |

Пример: `/addword contact_cta свяжитесь со мной`

Группа `personal_deal` работает наоборот — она защищает обычные сообщения.
Если бот удаляет объявления ваших подписчиков («продаю», «сдаю», «ищу
мастера»), добавляйте характерные фразы туда.

**Про пороги.** Чем больше число, тем реже срабатывает бот. По умолчанию:
удаление от 4 баллов, блокировка от 6. Если бот придирается — поднимите
на 1–2. Если пропускает — опустите, но осторожно.

### Работа с людьми

| Команда | Что делает |
|---|---|
| `/whitelist` | показать белый список |
| `/whitelist add 123456789` | никогда не трогать этого человека |
| `/whitelist del 123456789` | убрать из белого списка |
| `/unban 123456789` | разблокировать в чате |

ID человека виден в каждом уведомлении о спаме. Узнать заранее: попросите
его написать боту [@userinfobot](https://t.me/userinfobot).

**Кого бот не трогает никогда** — их в белый список добавлять не нужно:

- вас (владельца);
- администраторов чата;
- анонимных администраторов;
- связанный канал и его посты;
- самого себя.

### Прочие настройки

| Команда | Что делает |
|---|---|
| `/service вкл` / `/service выкл` | удалять ли «X теперь в группе» |
| `/media вкл` / `/media выкл` | удалять ли кружки и голосовые от новичков |
| `/purge` | стереть сохранённые тексты из журнала |

**Про `/media`.** По умолчанию выключено. Включайте, если через кружочки
и голосовые пошла реклама. Проверка касается только тех, кто ещё ни разу
не писал в чате, — обычное общение не затрагивается.

### Команда в самом чате

| Команда | Что делает |
|---|---|
| `/id` | показывает ID чата и ваш ID |

Нужна один раз при настройке. Работает только для администраторов чата.

## Что бот делает сам

**Ловит спам** по сочетанию признаков, а не по отдельным словам. Проверяет
текст и подписи к медиа, отредактированные сообщения, скрытые под текстом
ссылки, пересылки из чужих каналов, имя и @username отправителя, повторы
от разных аккаунтов.

Понимает попытки обхода: «Р А Б О Т А», латиница вместо кириллицы, цифры
вместо букв, невидимые символы внутри слов.

**Удаляет всё, что написал нарушитель.** Если бот пропустил первые сообщения
спамера и поймал только третье — при срабатывании уберёт все за последние
двое суток. Telegram не даёт удалять сообщения старше 48 часов.

**Убирает служебные сообщения** — «X теперь в группе», «X покинул группу»,
смена названия и фото чата. Настройками Telegram их скрыть нельзя.

**Следит за собой:** раз в час проверяет, не отобрали ли права
администратора, раз в сутки в 10:00 присылает сводку «работаю»,
чистит журнал старше 90 дней.

## Если бот ошибся

**Удалил нормальное сообщение.**

1. Нажмите **✅ Не спам** под уведомлением — человек разблокирован
   и добавлен в белый список.
2. Пришлите боту тот же текст — он покажет, какие признаки сработали.
3. Уберите виновную фразу: `/delword фраза`, или поднимите порог:
   `/threshold delete 5`.
4. Если это личное объявление подписчика — добавьте характерную фразу
   в защитную группу: `/addword personal_deal ищу мастера`.

**Пропустил спам.**

1. Перешлите сообщение боту.
2. Посмотрите, сколько баллов не хватило.
3. Нажмите **🚫 Запомнить как спам**.
4. Если баллов оказалось 0 и признаков нет вовсе — значит формулировка
   боту незнакома совсем. Добавьте ключевую фразу через `/addword`.

## Настройки в файле

Обычно не нужны — всё меняется командами. Файл `.env` лежит на сервере
в каталоге `/opt/moderator`.

| Настройка | Что означает |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_ID` | ваш Telegram ID — кому подчиняется бот |
| `CHAT_IDS` | ID чатов через запятую; можно несколько |
| `MODE` | режим: `observe`, `soft`, `enforce` |
| `NOTIFY_ADMIN` | присылать ли уведомления |
| `WHITELIST_IDS` | кого не трогать, через запятую |
| `DELETE_SERVICE_MESSAGES` | удалять ли «X теперь в группе» |
| `BLOCK_NEWCOMER_MEDIA` | удалять ли кружки и голосовые от новичков |
| `STORE_MESSAGE_TEXT` | хранить ли тексты сработавших сообщений |
| `DAILY_REPORT_HOUR` | час ежедневной сводки, `выкл` — не присылать |
| `LOG_RETENTION_DAYS` | сколько дней хранить журнал |
| `DB_PATH`, `LOG_LEVEL` | файл базы и подробность журнала |

После правки файла нужен перезапуск: `/restart` в боте или
`sudo systemctl restart moderator` на сервере.

## Если бот перестал отвечать

Проверьте диагностикой — она скажет, что именно сломалось:

```bash
ssh root@ВАШ_IP 'cd /opt/moderator && .venv/bin/python -m deploy.diagnose'
```

Она проверяет токен, права в чате, режим приватности, доступность вашей
лички, список команд, работу фильтра, базу и возможность сохранять
настройки. Токен нигде не печатает.

Перезапустить бота:

```bash
ssh root@ВАШ_IP 'systemctl restart moderator'
```

Посмотреть журнал:

```bash
ssh root@ВАШ_IP 'journalctl -u moderator -n 50'
```

## Что хранится о людях

Дата, ID чата, ID нарушителя, баллы, причина, результат и текст
**сработавшего** сообщения. Плюс номера сообщений участников за последние
двое суток — только номера, без текста, чтобы удалить их при блокировке.

Тексты обычных сообщений не сохраняются никогда. Записи старше 90 дней
удаляются автоматически. Стереть всё накопленное: `/purge`.
