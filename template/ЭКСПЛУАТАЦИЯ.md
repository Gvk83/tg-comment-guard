# Бот-модератор чата комментариев

Удаляет спам в комментариях к каналу и блокирует спамеров. Работает на сервере
круглосуточно, перезапускается сам.

## Три режима

| Режим | Что делает |
|---|---|
| `observe` | только сообщает вам о находках, ничего не удаляет — безопасный старт |
| `soft` | удаляет спам, но никого не банит |
| `enforce` | удаляет спам и банит отправителя при высокой уверенности |

Режим переключается прямо в Telegram — кнопкой в меню или командой `/mode soft`.
Выбор сохраняется и переживает перезапуск.

## Управление — всё из Telegram

Отправьте боту в личку `/menu` — появится меню с кнопками. Сервер и SSH
для повседневной работы не нужны.

### Кнопки меню

| Кнопка | Что делает |
|---|---|
| 📊 Состояние | режим, пороги, белый список |
| 📈 Статистика | срабатывания за сутки и за неделю |
| 📋 Последние | кто, когда, за что, что сделано и **текст сообщения** |
| 🚫 Образцы спама | сохранённые образцы |
| 👀 Наблюдение / 🧹 Мягкий / 🛡 Боевой | переключение режима, сохраняется |
| ⏸ Приостановить / ▶️ Возобновить | временно выключить проверку |
| 🔄 Перезапустить | перезапуск бота |

### Команды

Работают только для владельца (`ADMIN_ID` в `.env`).

| Команда | Что делает |
|---|---|
| `/menu` | меню с кнопками |
| `/status` | режим и настройки |
| `/stats` | сводка за сутки и неделю |
| `/last` | последние срабатывания с текстом сообщений |
| `/samples` | сохранённые образцы спама |
| `/spam текст` | запомнить образец вручную |
| `/delsample 5` | удалить образец |
| `/mode observe\|soft\|enforce` | сменить режим, сохраняется |
| `/pause`, `/resume` | приостановить и возобновить проверку |
| `/restart` | перезапустить бота |
| `/check текст` | проверить текст, не трогая чат |
| `/addword группа фраза` | добавить фразу в правила |
| `/delword фраза` | убрать добавленную фразу |
| `/threshold ban 7` | порог блокировки (больше — реже) |
| `/threshold delete 5` | порог удаления |
| `/reload` | перечитать правила |
| `/whitelist` | показать белый список |
| `/whitelist add 12345` | не трогать этого человека |
| `/whitelist del 12345` | убрать из белого списка |
| `/unban 12345` | разблокировать в чате |
| `/service вкл\|выкл` | удалять ли «X теперь в группе» |
| `/media вкл\|выкл` | удалять ли кружки и голосовые от новичков |
| `/purge` | стереть сохранённые тексты из журнала |

Все изменения сохраняются и переживают перезапуск: режим и белый список
пишутся в `.env`, добавленные фразы и пороги — в `data/custom_rules.yml`
(обновление кода их не затирает).

В самом чате комментариев команда `/id` (от админа) покажет ID чата.

Пауза (`/pause`) — это не остановка службы: бот остаётся запущенным, но
ничего не проверяет и не удаляет. Для повседневной работы этого достаточно,
полная остановка через сервер не нужна.

## Управление на сервере (обычно не нужно)

```bash
sudo systemctl status moderator     # состояние
sudo systemctl restart moderator    # перезапустить
sudo systemctl stop moderator       # остановить
sudo systemctl start moderator      # запустить
journalctl -u moderator -f          # смотреть журнал в реальном времени
journalctl -u moderator -n 100      # последние 100 строк журнала
```

Автозапуск после перезагрузки сервера включается один раз:

```bash
sudo systemctl enable moderator
```

## Служебные сообщения «X теперь в группе»

Бот удаляет их автоматически — вместе с «X покинул группу», сменой названия
и фото чата. Настройками Telegram эти сообщения не скрыть, удалить их может
только бот с правом удаления.

Работает во всех режимах, включая `observe`. Отключается в `.env`:

```
DELETE_SERVICE_MESSAGES=false
```

Уже накопившиеся старые сообщения бот не тронет — он видит только новые.
Telegram также запрещает ботам удалять сообщения старше 48 часов.

## Как добавить своё правило

Проще всего — командой боту:

```
/addword contact_cta свяжитесь со мной
```

Правило применится сразу. Убрать: `/delword свяжитесь со мной`.

Если нужно поправить встроенные правила — они в `bot/rules.yml`:

```yaml
  contact_cta:
    - пиши в лс
    - твоя новая фраза
```

Затем на сервере:

```bash
sudo systemctl restart moderator
```

Или отправьте боту в личку `/reload` — правила перечитаются без перезапуска.

## Как добавить человека в белый список

В файле `.env` добавьте его Telegram ID через запятую:

```
WHITELIST_IDS=123456789,987654321
```

Или проще — командой боту: `/whitelist add 123456789`.

ID человека виден прямо в уведомлении о спаме. Узнать заранее: попросите его
написать боту [@userinfobot](https://t.me/userinfobot).

Администраторы чата, владелец канала и сам бот защищены всегда — их
в белый список добавлять не нужно.

## Что делать при ложном срабатывании

1. Пришлите боту в личку `/check <текст сообщения>` — увидите, какие признаки сработали.
2. Если виновата конкретная фраза — уберите её из `bot/rules.yml`, затем `/reload`.
3. Если сработало сочетание признаков — поднимите порог командой боту:
   `/threshold delete 5` или `/threshold ban 7`. Больше число — реже срабатывания.
4. Быстрее всего — кнопки прямо под уведомлением о спаме:
   **✅ Не спам** (разблокирует и добавит в белый список) и
   **🔓 Разблокировать**.

## Что бот проверяет

- обычный текст и подписи к фото и видео;
- отредактированные сообщения;
- **ссылки, спрятанные под текстом** (слово «тут» с адресом внутри);
- пересылки из других каналов;
- имя и @username отправителя;
- повторы одного сообщения от разных аккаунтов;
- по желанию — видео-кружки, голосовые и истории от тех, кто ещё не писал
  в чате (`/media вкл`, по умолчанию выключено).

## База образцов спама

Под каждым уведомлением есть кнопка **🚫 Запомнить как спам**. Нажали — текст
попал в базу, и похожие сообщения удаляются сразу, не разбираясь в баллах.

Сравнение идёт по «скелету» текста: без цифр, пробелов и знаков препинания.
Поэтому «Работа на дому, 5000 в день, пиши в лс» и «Работа на дому, 7000 в день,
пиши в лс» — это один образец. Переставленные слова и мелкие правки тоже
узнаются (совпадение от 82%).

Добавить образец вручную: `/spam текст объявления`.
Посмотреть список: `/samples`. Удалить лишний: `/delsample 5`.

Слишком короткие тексты (меньше 20 букв) не сохраняются — иначе под них
попадали бы обычные реплики.

## Бот сам следит за собой

- Раз в час проверяет, что у него не отобрали права администратора.
  Если права пропали — пришлёт предупреждение.
- Раз в сутки в 10:00 присылает короткую сводку «работаю» со статистикой.
  Отключить: в `.env` поставить `DAILY_REPORT_HOUR=выкл`.
- Записи журнала старше 90 дней удаляются сами (`LOG_RETENTION_DAYS`).

## Какие данные хранятся

Дата, ID чата, ID нарушителя, баллы, причина, что сделано — и текст
**сработавшего** сообщения, чтобы вы видели его в `/last` и могли добавить
в образцы.

Тексты обычных сообщений не сохраняются никогда. Записи старше 90 дней
удаляются автоматически. Отключить хранение текстов: `STORE_MESSAGE_TEXT=false`
в `.env`. Стереть накопленное: команда `/purge`.

## Запуск на своём компьютере (для проверки)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # затем впишите BOT_TOKEN и ADMIN_ID
.venv/bin/python -m bot.main
```

Тесты (pytest ставится отдельно, в зависимости бота он не входит):

```bash
.venv/bin/pip install pytest
.venv/bin/python -m pytest tests -q
```

## Проверка, если что-то не так

На сервере:

```bash
cd /opt/moderator && .venv/bin/python -m deploy.diagnose
```

Проверит токен, права в чате, режим приватности, доступность вашей лички,
список команд, фильтр, базу и возможность сохранять настройки. Токен
не печатает.
