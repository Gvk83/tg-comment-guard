# Модератор комментариев Telegram

Бот, который чистит комментарии под постами вашего Telegram-канала:
удаляет спам, банит спамеров и убирает надписи «X теперь в группе».

**Программировать не нужно.** Разворачивается за полчаса вместе с ИИ-агентом.

---

# Как запустить

Скопируйте эту фразу и отправьте её ИИ-агенту:

```
Склонируй репозиторий https://github.com/Gvk83/tg-comment-guard,
прочитай в нём файл skill/ПРОМПТ.md и выполни то, что там написано.
Мне нужен бот-модератор для комментариев моего Telegram-канала.
```

Дальше агент сам задаст вопросы, соберёт проект, прогонит тесты, проведёт вас
через аренду сервера и запустит бота.

### Куда именно вставлять

Подойдёт любой инструмент, который умеет работать с файлами и командами:

| Инструмент | Где именно |
|---|---|
| **Claude** (приложение для Mac/Windows) | вкладка **Code** |
| **Claude Code** | в терминале команда `claude` |
| **Codex** (приложение OpenAI) | режим работы с проектом |
| **Codex CLI** | в терминале команда `codex` |
| **Cursor**, **Windsurf**, **Antigravity** | панель чата (режим Agent, не «спросить») |
| Qwen Code, DeepSeek, GLM и другие CLI-агенты | обычный чат агента |

Общее правило: если инструмент умеет **сам создавать файлы и выполнять
команды** — фраза сработает.

<details>
<summary>Если инструмент этого не умеет (ChatGPT или DeepSeek на сайте)</summary>

В браузерных чатах агент не может ни скачать репозиторий, ни создать файлы
у вас на компьютере — он только пишет текст. Тогда:

1. Откройте [`skill/ПРОМПТ.md`](skill/ПРОМПТ.md).
2. Скопируйте весь текст **после горизонтальной черты** (начинается со слов
   «Ты — senior-разработчик Telegram-ботов…»).
3. Вставьте в чат.

Дальше агент будет диктовать вам, какие файлы создать и какие команды
выполнить, а вы — делать это руками. Это работает, но долго и легко ошибиться.

**Проще поставить бесплатный Claude Code или Codex CLI** — тогда всё сделает
агент. Спросите об этом у той же нейросети, она подскажет установку.

</details>

<details>
<summary>Поставить как постоянный навык — Claude Code и Codex</summary>

Тогда не придётся каждый раз вставлять фразу: достаточно сказать «поставь
мне бота-модератора для комментариев канала», и навык подхватится сам.

Формат навыков у Claude Code и Codex одинаковый, поэтому команда ставит
его сразу в оба (лишнее просто не создастся):

```bash
git clone --depth 1 https://github.com/Gvk83/tg-comment-guard /tmp/tcg && \
for dir in ~/.claude/skills ~/.codex/skills; do \
  mkdir -p "$dir/telegram-comment-guard" && \
  cp -R /tmp/tcg/skill/. /tmp/tcg/template "$dir/telegram-comment-guard/"; \
done && rm -rf /tmp/tcg && echo "Навык установлен"
```

После установки **перезапустите** Claude Code или Codex, иначе навык
не появится.

Cursor хранит постоянные правила только в своих настройках
(Customize → Rules), файлом их не поставить — там пользуйтесь фразой выше.

</details>

## Что понадобится

- Telegram-канал с включёнными комментариями;
- бот, созданный через [@BotFather](https://t.me/BotFather) (агент подскажет как);
- банковская карта для аренды сервера — около **500 ₽ в месяц**;
- полчаса времени.

## Зачем это

Если у вашего Telegram-канала — или у канала вашего клиента — включены
комментарии, туда рано или поздно приходит спам.

Сейчас это особенно заметно: рассылку ведут не люди, а боты. Одно и то же
объявление прилетает по несколько раз за день, а под удачным постом —
несколько десятков раз, с разных аккаунтов и с чуть изменёнными цифрами.

> Работа. В день 2-3 часа. Ничего сложного нету. Пишите https://t.me/…
>
> закроем все твои финансовые вопросы, от 16к за одну смену, пиши по контакту
>
> 10 000р в день заработать легче чем думаешь, пиши @…

Вручную это не вычистить: пока вы спите, комментарии уже засыпаны.

Плюс чат засоряется служебными надписями о том, что кто-то вошёл или вышел.
Скрыть их настройками Telegram нельзя — это может сделать только бот.

**Этот бот убирает и то, и другое.** Один бот обслуживает от одного
до нескольких чатов сразу — удобно, если ведёте несколько каналов или
работаете с клиентами. Платить нужно только за сервер, около 500 ₽ в месяц:
ни подписок, ни платных нейросетей, ни оплаты за каждый чат.

## Что умеет

**Ловит спам** по сочетанию признаков, а не по отдельным словам. Обычный
комментарий со словом «работа» или «деньги» он не тронет, а объявление
о заработке со ссылкой и призывом писать в личку — удалит.

Что проверяется:

- обычный текст и подписи к фото и видео;
- отредактированные сообщения — правка задним числом не помогает;
- **ссылки, спрятанные под текстом** (слово «тут» с адресом внутри);
- пересылки из чужих каналов;
- имя и @username отправителя — спамеры пишут объявление прямо в профиле;
- повторы одного текста от разных аккаунтов;
- видео-кружки, голосовые и истории от тех, кто ещё ни разу не писал
  (по желанию).

**Понимает попытки обхода.** «Р А Б О Т А», «рaботa» латиницей, «раб0та»
цифрами, невидимые символы внутри слов — всё приводится к обычному виду
перед проверкой.

**Никого не трогает зря.** Владелец, администраторы чата, сам бот и белый
список защищены всегда. Есть режим наблюдения, в котором бот только сообщает
о находках и ничего не удаляет — с него и надо начинать.

**Учится на ваших примерах.** Под каждым уведомлением есть кнопка «Запомнить
как спам». Нажали — похожие сообщения удаляются сразу. Цифры не важны:
«5000 в день» и «9000 в день» считаются одним объявлением.

**Управляется из Telegram.** Кнопки под полем ввода, меню команд, смена
режима, пауза, перезапуск, статистика, журнал срабатываний, белый список,
разбан. Сервер и SSH нужны только один раз при установке.

Пропущенный спам добавляется пересылкой: переслали боту сообщение — он
показал, каких признаков не хватило, и предложил запомнить образец.
Все команды подробно расписаны в [РУКОВОДСТВЕ](template/РУКОВОДСТВО.md).

**Следит за собой.** Раз в час проверяет, не отобрали ли у него права
администратора. Раз в сутки присылает сводку «работаю». Перезапускается сам
после сбоя и после перезагрузки сервера.

## Что насчёт встроенного антиспама Telegram

В группах от 200 участников есть настройка «Активный антиспам-фильтр».
**Включите её — она не мешает боту, они дополняют друг друга.**

| | Антиспам Telegram | Этот бот |
|---|---|---|
| Удаляет спам | да | да |
| **Банит спамера** | **нет** — человек остаётся и пишет снова | да, и удаляет все его прошлые сообщения |
| Служебные «X теперь в группе» | нет | да |
| Сообщает вам | только если сами зайдёте в «Недавние действия» | сразу, с текстом и кнопками |
| Настройка под ваш чат | никакой | пороги, словари, белый список, образцы |

Telegram сам называет свой фильтр экспериментальным и предупреждает
о ложных срабатываниях. Бот знает о нём: если Telegram успел удалить
сообщение первым, бот не считает это ошибкой и всё равно банит отправителя.

## Три режима

| Режим | Что делает |
|---|---|
| **Наблюдение** | только сообщает о находках, ничего не удаляет |
| **Мягкий** | удаляет спам, но никого не банит |
| **Боевой** | удаляет спам и банит отправителя при высокой уверенности |

Переключается кнопкой в Telegram. Начинать всегда стоит с наблюдения.

## Что хранится

Дата, ID чата, ID нарушителя, баллы, причина, результат и текст
**сработавшего** сообщения. Тексты обычных сообщений не сохраняются никогда.
Записи старше 90 дней удаляются автоматически. Всё накопленное стирается
одной командой.

Сервер имеет смысл брать российский — так проще с хранением данных
пользователей.

## Если что-то не работает

Запустите диагностику на сервере — она проверит всё разом и скажет, что не так:

```bash
/opt/moderator/.venv/bin/python -m deploy.diagnose
```

Самая частая причина — включённый режим приватности в BotFather. Из-за него
бот не видит комментарии вообще. Разбор этой и других ловушек —
в [`skill/ЛОВУШКИ.md`](skill/ЛОВУШКИ.md).

без внешних сервисов, без ИИ-классификаторов и платных API.
