# Модератор комментариев Telegram

Бот, который чистит комментарии под постами вашего Telegram-канала:
удаляет спам, банит спамеров и убирает надписи «X теперь в группе».

Разворачивается за полчаса вместе с ИИ-агентом. Программировать не нужно.

---

## Зачем это

Если у канала включены комментарии, в них приходит одно и то же:

> Работа. В день 2-3 часа. Ничего сложного нету. Пишите https://t.me/…
>
> закроем все твои финансовые вопросы, от 16к за одну смену, пиши по контакту
>
> 10 000р в день заработать легче чем думаешь, пиши @…

Плюс чат засоряется служебными надписями о том, что кто-то вошёл или вышел.
Скрыть их настройками Telegram нельзя — это может сделать только бот.

Этот бот убирает и то, и другое.

## Что умеет

**Ловит спам** по сочетанию признаков, а не по отдельным словам. Обычный
комментарий со словом «работа» или «деньги» он не тронет, а объявление
о заработке со ссылкой и призывом писать в личку — удалит.

Что именно проверяется:

- обычный текст и подписи к фото и видео;
- отредактированные сообщения — правка задним числом не помогает;
- **ссылки, спрятанные под текстом** (слово «тут» с адресом внутри);
- пересылки из чужих каналов;
- имя и @username отправителя — спамеры пишут объявление прямо в профиле;
- повторы одного текста от разных аккаунтов;
- видео-кружки, голосовые и истории от тех, кто ещё ни разу не писал
  (по желанию).

**Понимает попытки обхода.** «Р А Б О Т А», «рaботa» латиницей, «раб0та»
цифрами, невидимые символы внутри слов — всё приводится к обычному виду
перед проверкой.

**Никого не трогает зря.** Владелец, администраторы чата, сам бот и белый
список защищены всегда. Есть режим наблюдения, в котором бот только сообщает
о находках и ничего не удаляет — с него и надо начинать.

**Учится на ваших примерах.** Под каждым уведомлением есть кнопка «Запомнить
как спам». Нажали — похожие сообщения удаляются сразу. Цифры не важны:
«5000 в день» и «9000 в день» считаются одним объявлением.

**Управляется из Telegram.** Кнопки под полем ввода, меню команд, смена
режима, пауза, перезапуск, статистика, журнал срабатываний, белый список,
разбан. Сервер и SSH нужны только один раз при установке.

**Следит за собой.** Раз в час проверяет, не отобрали ли у него права
администратора. Раз в сутки присылает сводку «работаю». Перезапускается сам
после сбоя и после перезагрузки сервера.

## Три режима

| Режим | Что делает |
|---|---|
| **Наблюдение** | только сообщает о находках, ничего не удаляет |
| **Мягкий** | удаляет спам, но никого не банит |
| **Боевой** | удаляет спам и банит отправителя при высокой уверенности |

Переключается кнопкой в Telegram. Начинать всегда стоит с наблюдения.

## Что хранится

Дата, ID чата, ID нарушителя, баллы, причина, результат и текст **сработавшего**
сообщения. Тексты обычных сообщений не сохраняются никогда. Записи старше
90 дней удаляются автоматически. Всё накопленное стирается одной командой.

Сервер имеет смысл брать российский — так проще с хранением данных
пользователей.

## Сколько стоит

Около **500 ₽ в месяц** — минимальный VPS плюс публичный IP-адрес.
Ни платных API, ни подписок. Бот занимает меньше 200 МБ памяти.

## Как установить

### С ИИ-агентом (рекомендуется)

**Claude Code:** выполните одну команду —

```bash
git clone --depth 1 https://github.com/Gvk83/tg-comment-guard /tmp/tcg && \
mkdir -p ~/.claude/skills/telegram-comment-guard && \
cp -R /tmp/tcg/skill/* /tmp/tcg/template ~/.claude/skills/telegram-comment-guard/
```

— и скажите:

> Поставь мне бота-модератора для комментариев моего канала

**Codex, Cursor, Antigravity, Windsurf, Qwen, DeepSeek и другие:**
откройте [`skill/ПРОМПТ.md`](skill/ПРОМПТ.md), скопируйте всё после разделителя
и вставьте в чат с агентом.

Агент задаст несколько вопросов, соберёт проект, прогонит тесты, проведёт вас
через аренду сервера и запустит бота. Готовый проверенный код лежит
в [`template/`](template/) — агент возьмёт его оттуда, а не будет сочинять заново.

### Вручную

Весь код в [`template/`](template/). Инструкция по эксплуатации —
[`template/ЭКСПЛУАТАЦИЯ.md`](template/ЭКСПЛУАТАЦИЯ.md). Установка на сервер —
[`template/deploy/install.sh`](template/deploy/install.sh).

## Что понадобится

- Telegram-канал с включёнными комментариями;
- бот, созданный через [@BotFather](https://t.me/BotFather);
- банковская карта для аренды сервера;
- полчаса времени.

## Если что-то не работает

Запустите диагностику на сервере — она проверит всё разом и скажет, что не так:

```bash
/opt/moderator/.venv/bin/python -m deploy.diagnose
```

Самая частая причина — включённый режим приватности в BotFather. Из-за него
бот не видит комментарии вообще. Разбор этой и других ловушек —
в [`skill/ЛОВУШКИ.md`](skill/ЛОВУШКИ.md).

## Технически

Python 3.10+, [aiogram 3](https://docs.aiogram.dev/), SQLite, systemd.
Три зависимости, около 1500 строк, 63 автоматических теста. Без Docker,
без внешних сервисов, без ИИ-классификаторов.
